# ADR-0004 目录安全：黑名单审核制，非白名单

## 状态
已定案（2026-11-03）

## 决策
用户将推荐的白名单制反转为黑名单制：只有命中目录黑名单的操作走人工
Approval Gate，其余一律放行。初版黑名单为空；条目只能经审核流程添加，
不需要改代码。

## 理由
- 个人机器上白名单（默认拒绝）会产生持续审批噪音。
- 黑名单"默认放行 + 例外审批"更符合本地单用户场景的安全模型。

## 待办
- 种子候选（C:\Windows、C:\Program Files、C:\ProgramData 等系统目录）待用户审核后添加。
- 公司数据目录由用户后续补录。
