# ADR-0001 引擎选择：默认 Jarvis，Codex 仅显式指定

## 状态
已定案（2026-11-03）

## 决策
每个 Task 默认跑 Jarvis 引擎；仅当用户对该 Task 显式指定 Codex 时才调用 Codex。
不做 LLM 自动路由，不做公司数据自动判定（原 Q2 方案中的"涉及公司数据用 jarvis"
由秘书判定，最终简化为：默认 jarvis，用户指定 codex 时才调 codex）。

## 理由
- 单人使用规模下，自动路由意味着多一次模型调用，且"公司数据判定"是不可测的启发式，零收益。
- 显式指定无歧义、可审计；用户在任务提交时可写"用 codex 跑"即可切换。

## 编号说明
本仓 ADR 从 0001 起独立编号，与姊妹仓（Jarvis 0011+、数字主持人 0022+）不续接。

## 考虑过但推迟的选项
- LLM 路由 / 公司数据自动判定：出现多用户规模或真实"非 Codex 不可"能力需求时重开。
