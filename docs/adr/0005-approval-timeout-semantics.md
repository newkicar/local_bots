# ADR-0005 审批超时：30 分钟自动拒绝，副作用清单照常输出

## 状态
已定案（2026-11-03）

## 决策
waiting-approval 态的 Run 超时 30 分钟（参数 LD_APPROVAL_TIMEOUT_MIN，计时自
进入等待审批态起算）后自动拒绝，记录 rejected(reason=approval_timeout)。
审批被拒或任务取消时：当前步立即停止、已发生的副作用不回滚，照常写入
Side-Effect Ledger。

## 理由
- 手机远程流程中审批可能无人值守，自动拒绝是安全默认。
- "停止后续 + 出副作用清单"统一了取消/超时/拒绝三种终止路径的语义，
  清单让用户自行决定需要手动撤销什么。
